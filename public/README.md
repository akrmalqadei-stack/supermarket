# 🛒 SuperMarket Pro

نظام إدارة سوبرماركت احترافي متكامل يعمل بالكامل في المتصفح بدون سيرفر.

## ✨ المميزات

- 🛒 نقطة بيع كاملة مع باركود وفئات وطرق دفع
- 📦 إدارة المنتجات مع تنبيه المخزون المنخفض
- 👥 إدارة العملاء مع رصيد آجل
- 🧾 الفواتير مع طباعة وتصدير CSV
- 💵 الصندوق مع فتح وإغلاق وجرد
- 📊 تقارير ورسوم بيانية
- 👤 3 أدوار (مدير نظام، مدير فرع، كاشير)
- 🏢 إدارة فروع متعددة
- 🌙 وضع ليلي/نهاري
- 💾 نسخ احتياطي JSON
- 📱 متجاوب مع كل الأجهزة
